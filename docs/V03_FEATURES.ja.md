# UsagiLang v0.3.0-alpha 日本語機能ガイド

UsagiLang は『ちいかわ』のうさぎの発声表現に着想を得た非公式の創作プログラミング言語です。言語上の機能は本プロジェクト独自の定義であり、原作の公式な翻訳や意味を示すものではありません。

**v0.3 の方針:** 日本語のうさぎ風キーワードを推奨し、韓国語の別名を同等に扱います。v0.2 の旧キーワードも後方互換のため受け付けます。

## v0.3 キーワード対応表

| 機能 | 推奨する日本語 | 韓国語の別名 | 以前のキーワード（一例） |
|---|---|---|---|
| for の対象指定（in） | `ウラウラ` | `우라우라` | `in`, `안에` |
| 論理積（and） | `ウルウル` | `우루우루` | `and`, `그리고`, `&&` |
| 論理和（or） | `ヤハヤハ` | `야하야하` | `or`, `또는`, `||` |
| 論理否定（not） | `イヤハ` | `이야하` | `not`, `아님`, `!` |
| 値なし（null） | `ナイナイ` | `나이나이` | `ナシ`, `없음`, `null` |
| モジュール読み込み（import） | `ハイ` | `하이` | `import`, `インポート`, `가져와` |
| モジュールの別名（as） | `ウララ` | `우라라` | `as`, `として`, `별칭` |
| 例外処理開始（try） | `プルップラッ` | `푸룻푸랏` | `try`, `ためす`, `시도` |
| 例外捕捉（catch） | `ウギッ` | `우깃` | `catch`, `つかまえる`, `잡기` |

`フゥン` は引き続き else を表します。`throw` / `なげる` / `던지기` もそのまま使用します。値なしを `ウラ` で出力したときの表記は `ナイナイ` です。

## 例1: for と条件演算

```usagi
プルャ numbers = [1, 2, 3, 4, 5]
ツツウラウラ n ウラウラ numbers {
    ハァ n > 2 ウルウル イヤハ (n == 5) {
        ウラ n
    }
}
```

出力は `3` と `4` です。

## 例2: or と値なし

```usagi
プルャ value = ナイナイ
ハァ value == ナイナイ ヤハヤハ ウーラーヤハヤハ {
    ウラ "値なし"
}
ウラ value
```

## 例3: モジュールを読み込む

```usagi
ハイ "modules/math.usagi" ウララ 数学
ウラ 数学.square(4)
```

`ハイ` は UsagiLang が定めた import 用キーワードです。読み込めるのはローカルの `.usagi` ファイル、または登録済みの `pkg:` パッケージです。一般の Python モジュールは読み込めません。

```usagi
ハイ "pkg:helpers" ウララ helpers
```

オンライン Playground では現在、外部モジュールファイルや `pkg:` の読み込みは基本的に利用できません。

## 例4: 例外処理

```usagi
プルップラッ {
    なげる "テストエラー"
} ウギッ err {
    ウラ "エラー:", err
}
```

`ウギッ` が担うのは `catch`（例外捕捉）の役割です。`throw` の新しいキーワードはまだ決めていません。

## 日本語・韓国語の混在

```usagi
푸루야 values = [1, 2, 3]
ツツウラウラ n 우라우라 values {
    하아 n > 1 ウルウル ヤハ {
        ウラ n
    }
}
```

日本語と韓国語は同じ字句解析器で処理されます。

## 旧コードとの互換性

v0.2 の `in`、`and`、`or`、`not`、`ナシ`、`import`、`as`、`try`、`catch` および既存の別名は引き続き使用できます。ただし、値なしの表示表記は v0.3 で `ナイナイ` に変更されています。文字列表示を厳密に比較する既存のテストは更新が必要な場合があります。

## 実行方法

```bash
python -m pip install -e .
usagi run examples/v02.usagi
usagi check examples/v02.usagi
usagi repl
python -m unittest discover -s tests -v
```

新しいキーワードは通常の `.usagi` ファイルおよび `-c` でも利用できます。
